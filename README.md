# AI Graver v0.7.0

Рабочий Windows-прототип для первичной подготовки портрета перед открытием в Graver.

## Что делает

- Загружает JPG, PNG, BMP и TIFF.
- Переводит фото в оттенки серого (`8-bit grayscale`).
- Автоматически выравнивает яркость, усиливает локальные детали и тени.
- Автоматически выделяет человека нейросетью MediaPipe и заменяет фон на чёрный.
- Даёт выбор кадрирования: `до груди` или `полный рост`.
- Имеет компактную боковую панель и большую рабочую область предпросмотра.
- В режиме `Полный автомат` сразу после выбора фото обрабатывает и сохраняет результат, а затем проверяет его в найденном Graver.
- Настраивает тон под чёрный гранит, серый гранит или мрамор.
- Реконструирует лицо нейросетью GFPGAN 1.4 и отдельно усиливает микротекстуру кожи, морщины, глаза и волосы перед экспортом 3084×5526.
- Сохраняет отдельный цветной файл `*_restored_4k.png` и показывает его слева после обработки.
- Делает вертикальный холст `3084 × 5526 px`.
- Сохраняет PNG и, при включённой галочке, BMP с `83 DPI`.
- Запоминает настройки и путь к `graver5_x64.exe`.
- В установленной версии сохраняет настройки и результаты в `%APPDATA%\AI Graver`.
- Для проверки в Graver создаёт отдельный 8-битный BMP, открывает его через штатное окно Graver и ждёт подтверждение в журнале программы. Команды запуска станка не отправляются.

При первом удалении фона MediaPipe загружает локальную модель, поэтому первый предпросмотр может строиться дольше последующих. Для одиночных портретов фон удаляется автоматически. На тесных групповых фотографиях, где люди перекрывают друг друга, перед гравировкой обязательно проверьте края и при необходимости используйте более крупный исходник одного человека.

## Запуск

1. Установите Python 3.11+ с сайта [python.org](https://www.python.org/downloads/windows/), если Python ещё не установлен.
2. Откройте PowerShell в этой папке.
3. Выполните:

```powershell
py -m pip install -r requirements.txt
py app.py
```

4. Нажмите `Выбрать фото` → `Сделать для Graver`.
5. Готовые файлы появятся в папке `output`.

После первой установки можно запускать программу двойным кликом по `run_ai_graver.bat`.

## Сборка EXE

В PowerShell выполните:

```powershell
py -m pip install pyinstaller
.\build_exe.ps1
```

Готовый файл будет в `dist\AI_Graver\AI_Graver.exe`, а установщик — в `installer\AI_Graver_Setup_v<версия>.exe`.

## Автообновления

Программа автоматически проверяет новые версии в GitHub Releases репозитория `Ghost9289/AI_Graver`. Найденное обновление скачивается, тихо устанавливается и автоматически перезапускает AI Graver. Повторно скачивать установщик вручную не требуется. Публикация новых версий описана в `PUBLISH_RELEASE.md`.

## Важно перед работой со станком

Это базовая подготовка изображения, а не замена финальной калибровки станка. Сначала проверьте результат на тестовом материале и настройте в приложении контраст, детализацию и тени. Для обучения стилю конкретного ретушёра понадобятся пары `исходник → готовая ретушь`.

## Проверка в Graver 5

Кнопка **«Проверить в Graver»** создаёт совместимый 8-битный BMP, открывает его в
`graver5_x64.exe` и подтверждает по журналу Graver, что программа начала разбор
изображения. Она никогда не запускает станок и не отправляет команды CNC.
